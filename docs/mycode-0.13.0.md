## 功能

- IM/技能页面隐藏项目工作区，切回项目恢复会话。群聊从弹窗改为群列表与对话双栏，消息/输入框沿用应用风格，群间草稿分离，保留目录和记忆隔离、自动闲聊默认关闭与 Token 限额。
- 选区内容显示为可移除的引用块，悬停查看原文，发送时包含完整引用。无焦点且空输入框时上下键调出本会话用户消息，聚焦后恢复光标行为。
- 设置/对话提供 Enter 或 Ctrl+Enter 发送；插入换行时自动继续 `1`、`1.`、`1、` 等编号，可关闭。
- 服务商模型支持名称/ID 搜索、全选、取消全选、手动 ID 添加并自动勾选。刷新不丢失手动模型。未知模型参数继续标记官方未提供，不编造能力。
- 文件树左键看代码，HTML/HTM/SVG 右键选择内置或系统浏览器预览。仅运行静态页面；PHP/服务端框架仍需用户启动其开发服务。预览相对资源可用，站点根路径资源需要对应项目服务。
- 官方 MiniMax Code：npm 包 `@minimax-ai/code`，程序 `mcode`，通过 ACP 接入检测/安装/登录/项目会话。使用 CLI 自身认证与模型目录，不复用其他厂商订阅；当前官方 ACP 未声明图片/音频输入，界面不开放附件。

## 撤回与文件保护

每次普通项目消息发送前，在项目 `.mycode/turn-history` 建立快照。最后一条用户消息在一分钟内暂停且文件无变化时回填草稿；手动撤回以消息下方图标触发，撤回后重新建立 CLI 上下文，不继续使用包含已撤回内容的旧远端会话。

只自动恢复已捕获的结构化编辑，包含新建、修改、删除；恢复前核对文件哈希。当前草稿非空、后续用户编辑、未捕获的命令文件变更、项目外或排除目录编辑时拒绝覆盖并提示。旧消息需要先撤回较新的消息。数据库、网络操作、外部程序等副作用不做虚假回滚。项目快照限制 5,000 文件、单文件 16 MiB、合计 128 MiB，排除依赖、Git、构建缓存目录；超过限制不阻断对话，但不提供文件恢复保证。现有用户数据与凭据不迁移、不删除。

本地预览仅绑定 127.0.0.1，使用随机路径令牌、Host 与目录边界校验；内置 iframe 不启用同源权限或 Tauri IPC。外置预览最多运行一小时，内置关闭即停止。
