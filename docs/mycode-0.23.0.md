## MyCode 本轮功能

- 旧 `oauth.778.ink` 登录界面和命令退出应用；保留旧本地凭据文件，未清除用户资料。词元跳动模型授权密钥成为唯一可用账号入口。左下角显示可取得的昵称和余额；账号卡片显示头像、昵称、邮箱、账号 ID、总额度、已用额度及余额，字段只在平台返回时显示，并可直达模型管理。余额使用官方开放 API 的微元单位，模型列表不出现在账号卡片。平台没有为 API Key 公开承诺资料接口，因此昵称/头像可能不可用；可选资料查询设短超时，不会以模型 Key 伪造 OIDC 身份。
- 输入框空白时，无论输入框是否有焦点，上下键可查看本会话已发送的用户消息；其他输入控件、菜单和输入法不受影响。
- IM 新增 `/项目`（`/projects`）、`/切换项目 编号或名称`（`/switch-project`）、`/新建项目 名称 | 需求`（`/new-project`）；设置页展示命令用法。项目目录汇总历史会话库、默认工作区和已登记项目；新建目录沿用默认工作区设置及本地名称校验。选中项目后，后续消息进入该项目自己的 IM 会话。仅已有 IM owner 授权者能触发；明确回复完成推送仍按原会话继续。项目尚无可靠的“已完结”标记，因此查询时列出全部项目并说明范围。

词元跳动接口边界参见[开放平台 API](https://tokendance.space/docs/open-api.md)与[授权码换取 API Key](https://tokendance.space/docs/api-key-oauth.md)。账户 API Key 与独立的 OIDC 身份令牌用途不同；MyCode 不把前者用于身份令牌协议。
