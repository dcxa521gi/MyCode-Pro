# MyCode 0.26.0 更新与融合清单

日期：2026-11-25。基于已发布的 0.25.0，并保留此前 MyCode 定制及明确移除的功能。

## 1. 所有来源模型的自动能力标签

- 模型服务商列表、添加/编辑服务商的模型列表、会话模型选择器共用能力分类。
- 分类覆盖文本、视觉理解、生图、视频理解、生视频、语音识别、语音生成、音乐、向量嵌入、重排；不限于 Magpie。
- 优先使用服务商提供的输入模态、输出模态和接口类型。输入图片表示视觉理解，不直接认定为生图模型。
- 元数据缺失时，仅对已知模型名称作推断并明确标记；无法判断时显示“未提供能力信息”，不伪造支持。
- 可逐模型修正标签、保存修正并恢复自动分类。刷新模型保留用户明确修改的信息。
- 生图、生视频等非聊天模型保留在服务商配置及工作台中，不混入普通聊天模型列表。

## 2. Magpie 转发模型

- 添加 Magpie 服务商模板，默认地址 `http://127.0.0.1:3425/v1`；用户可以填写自己的转发地址及密钥。
- Magpie 模型发现使用 `/models?kind=all`，读取聊天、图片、视频等完整模型目录；保留服务商/模型/分组完整 ID，不截断路由前缀。
- 识别 Magpie 的嵌套 `modalities.input/output`、`kind` 等字段，接入统一能力标签。
- 普通聊天继续使用既有协议适配；工作台通过兼容的 Images/Videos REST 接口提交媒体请求。没有把 Magpie 订阅授权凭据导入 MyCode。
- 接口参考：<https://github.com/yetone/magpie>。是否允许远程访问、模型实际可用性及计费由用户的 Magpie/上游账号决定。

## 3. 工作台

侧边栏新增“工作台”，覆盖原布局、专注布局及全部 12 套主题的深浅色模式。

| 功能 | 执行方式 | 输出与限制 |
| --- | --- | --- |
| 文生图 | 选定模型的 `/images/generations` | 图片预览、打开文件、保存创作记录 |
| 图生图、图复刻 | `/images/edits`，上传参考图片 | PNG/JPEG/WebP 参考图；新生成文件保存在指定目录 |
| 文生视频、图生视频 | `/videos`，按任务 ID 查询进度及下载内容 | 异步任务保留服务端 ID，可手动刷新进度，不重新提交生成 |
| 图转提示词、视频转提示词 | 选定智能体分析本地参考资料 | 生成可编辑提示词文件；实际识别取决于所选模型和本地工具 |
| 生成小说、生成短剧 | 选定智能体完整创作任务 | 大纲、角色、正文/剧本、分镜等实际文件 |
| 生成绘本、PPT、短视频、视频复刻 | 选定智能体编排本地工具及指定图片/视频模型 | 需要对应模型、渲染/编辑工具；不把脚本或 Markdown 冒充视频/PPT 成品 |

- 每种功能记住所选模型；可选输出文件夹、参考文件。复杂创作额外绑定图片/视频模型，不由智能体静默替换成其他计费模型。
- 产物位于所选文件夹的 `.mycode/workbench/<任务编号>`；原始结果和任务记录保留，可打开任务继续处理。
- 原生层在计费请求前持久化任务意图。同一任务 ID 重试读取已有结果；参数改变会拒绝复用，避免重复计费。
- 视频下载采用流式写入，完成后才转为最终文件；图片按实际文件格式确定扩展名。
- 参考图最大 20 MB，图片下载最大 64 MB，视频最大 512 MB。服务商不支持接口时显示错误，不模拟成功。
- 智能体流程显示“任务结束，请检查产物”；会话结束本身不等于文件已通过人工验收。

## 4. ACP 插件引擎

来源：参考 Cindy 本地插件引擎/账号隔离能力，适配 MyCode 的标准 ACP v1 进程协议。

- 设置中可添加、编辑、启用、停用、移除 ACP 引擎清单；每个引擎可配置多个账号及模型。
- 安装前展示清单及本地可执行程序权限。保存时记录程序/入口脚本的 SHA-256；运行前校验，文件变化须重新审核保存。
- 支持初始化、认证方法选择、登录获取模型、创建会话、在服务端声明支持时加载原会话、模型/模式选择、流式文本、工具结果、权限请求、取消与退出。
- 监督模式按单次操作审批；计划模式必须由引擎声明支持，并拒绝写入类授权。取消后旧进程消息不能复活任务。
- 每个账号使用独立配置目录，清除继承的常见供应商密钥环境变量；停用和移除清单不会删除凭据、历史或用户文件。
- 远程 Host 可运行执行电脑已审核安装的 ACP 引擎；不允许控制端通过远程请求安装任意程序。
- **兼容边界**：这是可运行的标准 ACP v1 引擎适配，不能宣称完整兼容 Cindy Ghost v3 JavaScript Worker 插件包、Cindy 云插件、ACP v2 或第三方任意私有扩展。文件系统隔离依赖引擎自身；不是操作系统沙箱。

## 5. 跨设备模型组

来源：参考 Cindy 模型组共享/本地执行能力，沿用 MyCode 现有配对与 Host 协议。

- 将本地模型组规则发布到已配对的执行电脑，并限定可使用的项目；可撤销单项目授权。
- 远程电脑/手机通过同一 Host 目录选择模型组。路由、轮询游标及任务保存于执行电脑，客户端断开不重放任务。
- 任务创建事务内选择候选并推进游标；重复请求回执复用原任务，避免切换到另一个候选或重复执行。
- 修订号检测过期选择；后续发送重新检查项目授权、候选启用状态及账号存在，撤销后保留历史但拒绝新轮次。
- 账号与密钥不随模型组传输，需提前在执行电脑配置。暂不共享客户端私有 API 连接 ID。
- **边界**：Host 未取得真实额度的账号仍标记为未知，不承诺基于实时剩余额度的跨设备排序；远程 Host 本轮不执行额度耗尽后的自动会话迁移。

## 6. 本地执行任务中的账号自动切换

来源：参考 Cindy 多账号/模型组调度；复用 MyCode 已有 Claude/Codex 原生会话迁移。

- 模型组可开启“额度耗尽时自动切换账号”，默认关闭。
- 当前任务收到明确额度限制并停止生成后，在同一 CLI、同一模型的可用候选账号间切换，迁移原生会话后续接，不另开新会话重放用户整段需求。
- 每轮用户任务每个账号最多尝试一次；暂停、切换模型/组/工作目录/执行模式、会话变化会取消旧切换。
- 不把普通网络错误当成额度问题；排除 API 自定义模型、远程任务和编排子任务。迁移失败显示错误并停止自动尝试。
