# MyCode 跨网络连接

手机和电脑不必在同一网络。电脑主动连接中继，手机访问同一中继。电脑无需公网 IP 或路由器端口转发；手机和电脑都需联网，MyCode 需保持运行。

## 部署中继

准备一台安装 Docker Compose 的服务器和指向服务器的域名，允许服务器 80/443 端口。源代码包含 `scripts/remote-relay.mjs` 与 `relay/` 部署文件，无需安装额外 npm 依赖。

1. 复制 `relay/.env.example` 为 `relay/.env`，填写 `RELAY_DOMAIN` 和长随机的 `MYCODE_RELAY_REGISTRATION_KEY`。密钥只在服务器和电脑端配置，不要发送到聊天或提交 Git。
2. 在源代码根目录运行 `docker compose --env-file relay/.env -f relay/compose.yml up -d --build`。Caddy 为域名申请 HTTPS 证书。
3. 访问 `https://你的域名/v1/health` 应返回 `{"ok":true,"protocol":1}`。
4. 电脑「设置 → 手机连接」选择「远程中继」，填写 `https://你的域名` 和注册密钥，点击开启连接。
5. 安卓端扫码或粘贴电脑生成的完整配对信息。第一次配对后，手机切到移动网络也可继续原会话、切换电脑可用模型和处理审批。

也可在已有 Node.js 22 服务器运行 `node scripts/remote-relay.mjs`，默认监听 `127.0.0.1:8787`，由已有 HTTPS 反向代理转发。反向代理响应超时应至少 65 秒，关闭请求/响应正文日志。环境变量 `MYCODE_RELAY_REGISTRATION_KEY` 控制电脑注册；`HOST`/`PORT` 控制监听。可通过 `MYCODE_RELAY_TLS_CERT` 和 `MYCODE_RELAY_TLS_KEY` 使用已有证书直接提供 HTTPS。

## 配对与排障

配对码一次使用、10 分钟有效。刷新配对码可添加另一设备，不会撤销已连接设备；撤销单个设备或断开全部设备后，其旧授权不能继续操作。电脑重启或重新开启连接后需重新配对。授权和密钥保存在 Android Keystore 加密存储中。

直连仍可用于局域网、VPN 或已有可达地址。选择正确网卡地址，Windows 防火墙需允许显示的 TCP 端口。复制包含地址、证书和配对码的完整信息；不要只复制地址。证书校验失败、配对过期、服务离线和地址不可达会分别提示。

远程会话、审批、模型选择沿用电脑规则。模型 API 密钥留在电脑，中继没有解密密钥，不保存会话数据库。中继会看到连接 IP、房间标识、时间和密文长度。默认内存状态不跨服务重启保留；中继重启后在电脑重新开启连接。

中继程序已交付并不表示已经部署了公网服务器。真实手机摄像头、手机移动网络回连、服务器证书和代理配置需针对实际环境验收。
