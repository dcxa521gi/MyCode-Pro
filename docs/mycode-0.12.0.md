## 用户需求与实现边界

- 顶部开发/办公切换移除；从 IM/技能页选择会话时关闭工具页；交接提示中文；Token 使用 K/M/B/T/Q。
- 默认工作区由原生配置持久化；新建项目弹窗支持名称、默认父目录、已有文件夹、CLI 和模型。普通新会话沿用当前项目。
- CLI 子进程的 TEMP/TMP/TMPDIR、Claude 临时目录、npm/pip/uv/XDG 缓存落到项目 .mycode；Claude 计划文件放入 .mycode/plans；提交的粘贴附件复制到项目。缓存设置控制浏览器下载、应用更新、npm 安装缓存和临时附件。旧文件保持原位。
- 不将账号凭据复制进项目；厂商自身的认证/会话数据库与 Windows 系统缓存仍有各自固定位置。显式要求全权限智能体写入其他绝对路径时，工作目录配置不是文件系统沙箱。
- 存储位置只保留在工作区分组末尾的存储空间；刷新/安装状态可见；登录卡片移除测试标签。
- 模型供应商使用列表与详情面板、添加编辑弹窗、模型开关、全选/取消全选，TokenDance 保持显著入口。
- 启动检查已安装 CLI 版本；有更新显示通知，点击打开 CLI 设置，不自动安装。

## 群聊设计

群配置和历史位于所选目录/.mycode/groups/群ID/chat.json，成员工作目录位于同级 workspace。索引保存在应用数据目录，不存密钥。每个群至少两个成员且恰有一个主管；成员有昵称、职位、性格、性别、CLI、模型。

使用真实 submitSession 执行流程，独立短会话读取本群近期历史与记忆，不注入 MyCode 全局记忆。用户提问时被 @ 的成员优先，其他成员接续，主管最后评估并询问执行；勾选执行授权后仅主管执行，沿用工具审批。讨论使用计划意图，不自动实施工作。

自动闲聊默认关闭，重启也关闭；启用后随机间隔选择非主管成员讨论。Token 累计按厂商实际报告计算，每轮前检查限额；单个已开始回复可能超过限额。缺失用量或发生错误时停止闲聊。群界面关闭后已启用调度仍可运行，关闭应用停止。
