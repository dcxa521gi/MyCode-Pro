# MyCode 0.9.0

## 语音输入

设置 → 语音输入中选择 `xiaomimimo API` 或 `xiaomimimo Token Plan`。两种账号的密钥、地址不能混用。已有模型连接时，选择“使用已保存的小米 MiMo 账号”并点击“将此账号用于语音输入”，无需再次粘贴密钥。

Token Plan 默认地址为 `https://token-plan-cn.xiaomimimo.com/v1/chat/completions`，模型为 `mimo-v2.5-asr`；也支持官方新加坡、欧洲区域地址。旧版误拦截 Token Plan 的逻辑已移除。录音期间约每 4 秒提交一段音频并顺序插入草稿，停止时补齐最后一段；静音不会提交。转写不会自动发送消息，实际延迟取决于网络和服务响应。

本轮已用本机保存的 Token Plan 账号与合成测试语音调用真实 ASR 接口，成功返回文本。该验证不代表每个账号、麦克风或网络环境都已验收。

## 新任务与模型

- LOGO 点击直接跳到运行任务，连续点击循环切换；无运行任务时打开最近停止的会话，不弹出新建任务。
- 新建空白会话、切换其代理及首次执行前检查 CLI。发现未安装或更新版本后，可在弹窗中安装、重试或使用已有版本；安装期间显示不确定进度条，不伪造下载百分比。
- 自定义模型在前，已明确免费的模型其次，其余付费或账号模型最后。订阅账号的额度不等于免费价格，未公开价格的模型不会标成免费。
- Freebuff 可在设置 → CLI 代理工具中安装、检测、打开应用内官方终端。其当前公开 CLI 不支持无头提示词/JSON 会话协议，暂不支持从原生模型选择器启动，会话需在官方终端中操作。
- Windows Hermes 接入官方安装脚本，在 MyCode 数据目录内安装，避免修改全局 PATH。首次需下载 Python、代码和依赖，可能较久；失败时显示本地安装日志位置。本轮未完成其所有外部依赖的端到端安装验收。
- ZCode 的官方 CLI 当前需源码构建或自行提供发行地址；不能将桌面 EXE 当成 CLI。FX、Antigravity 仍受官方平台支持限制，这些情况会给出明确错误，不再把安装按钮直接跳到网页。

## 引用其他会话与过程显示

右键复制项目 ID 或会话 ID，粘贴到提问中。统一发送流程会读取本地匹配历史，将用户、助手及工具记录作为引用资料提供给所选代理，并包含来源 ID。当前会话不重复注入；最多 20 个会话，单个较长会话保留开头与最近内容，明确标出省略段，不能据此宣称读完全部历史。已删除或其他电脑上的会话无法由本地数据库恢复。

设置 → 对话增加“显示思考和命令过程”，默认开启、默认折叠，可手动展开。关闭只隐藏显示，不改变代理权限；待审批操作不会被隐藏。只显示代理实际公开返回的思考内容，不编造服务商未提供的内部推理。

## 无头浏览器

设置 → 电脑控制 → 无头浏览器，先安装再启用。MyCode 下载本地 Playwright MCP 和 Chromium；新建 Claude、Codex、OpenCode、MiMo Code 任务后，代理可通过 MCP 打开页面、读取页面结构、点击、填表和截图。

每个代理连接使用独立浏览器环境，不复用个人浏览器的登录 Cookie。操作仍受代理工具审批控制。关闭开关会撤销连接并退出相关浏览器；已提交到网站的操作不会因此撤销。本轮真实验证了 MCP 握手、页面导航、按钮点击和关闭后的连接退出。

## 收件箱是什么，如何使用

收件箱集中展示外部平台的工作事项。当前可连接 GitHub、GitLab、Linear、Jira、Azure DevOps；代码仓库平台主要是工单和 PR/MR，项目管理平台主要是任务工单。它与本地聊天历史、IM 机器人消息列表不同。

1. 打开一个有效工作项目；代码仓库来源应是 Git 仓库并配置正确的远程地址。纯本地文件夹不会凭空产生 GitHub 工单。
2. 在设置的收件箱连接项中配置相应账号；账号需要能访问目标仓库或工作区。回到收件箱选择来源、项目，刷新列表。
3. 用搜索、指派给我、状态、类型和时间筛选关注的事项。查看详情、讨论和支持的 PR 检查信息。
4. 将事项关联到本地会话，带着事项背景让智能体分析、实现或排查。会话卡片保留关联，方便从任务返回外部事项。可用操作取决于平台适配和账号权限。
5. 已读、静音与通知设置用于减少干扰，不会删除远程工单。项目右键静音子菜单和提醒时间已补齐中文。

如果只做本地开发、办公、笔记和模型对话，可以暂时不连接收件箱；不影响这些功能。
