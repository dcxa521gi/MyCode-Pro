# MyCode 0.22.0

日期：2026-10-15。本版以 MonoCode `633730d` → `5c21f01` 的 41 个提交为主基线，融合 MyCode 的模型路由、工作区、Windows 和双语界面；原有项目、凭据、会话、存储位置均不迁移。完整逐提交清单见 [上游核对表](mycode-0.22.0-upstream.md)。

## 用户要求与 MyCode 修复

- 顶部 MyCode LOGO 按运行任务轮换；编排工作中的子任务统一定位到可见的主管会话，连续点击不会一直回到同一会话。
- 技能、IM 机器人作为独立页面打开时不渲染工作区；工作区标题和操作提示按语言切换。工作区标题栏恢复一键移到左侧或右侧，折叠项目侧栏时也保留入口。
- 微信 iLink 连接状态统一为桥接器识别的 `connected`，网络中断会退避重试；授权账号的回复上下文加密保存在原有本机密钥存储中，重启后仍可用于完成通知。首次启用时需先给机器人发送一条消息以取得微信要求的回复上下文。旧账号与任务绑定不清除。
- 内置本地预览在其他页面暂时盖住时保留 iframe，返回后保持滚动和页面状态。

## MonoCode 主基线

- 智能体总览新增活动页、活动轨迹和新的简介卡；项目分组拖动排序、紧凑侧栏未读提示、快捷悬停说明与模型服务商分组得到同步。
- 会话与代理同步轮次 Token 合计、已消费交接摘要去重、拒绝快速模式后的用量处理、恢复后台任务状态、Pi 模型等待/技能 UTF-8 截断修复。
- 文件预览记住“预览/源码”，编辑器支持 Vue、Svelte、SCSS、Sass、Less 和 `.env`；远程 worktree 差异、引用路径解析、终端链接、产物阅读布局与问题提示音同步。
- Linux Host 无 systemd 时可后台运行并在重连时启动；Windows 安装包继续使用本机适配，不把 Windows 验证写成 Linux 实机验收。
- 上游服务商分组应用于 MyCode 已支持的 Pi、Hermes 等代理；OpenCode 保留 MyCode 自有价格分类并在分类内按上游服务商排序。上游 omp 在当前 Windows 可用代理列表中未启用，不能仅凭类型定义宣称可运行。
