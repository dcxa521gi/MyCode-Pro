# MyCode 0.7.0 使用与验证说明

## 使用

- 设置 → 服务商 → 模型服务商：保存连接、勾选模型并设置主模型；输入框模型菜单按服务商分组，可收藏。主模型在新建任务选择兼容智能体时优先使用。
- 设置 → 服务商 → CLI 代理工具：检测版本可查看当前和最新版本。应用内安装使用 MyCode 数据目录；切换“全局”使用电脑上的 CLI，切回应用内恢复保存的应用内路径。
- 设置 → IM 机器人 → 微信：获取二维码，用自己的微信扫码，保存允许用户与工作目录后连接。凭据加密保存在本机；仅绑定用户可发起任务。工具审批仍在桌面处理。
- 工作区标题栏按钮或设置 → 常规可以切换工作区位置。任务右键菜单可复制项目 ID / 会话 ID，悬停可查看实际返回的 Token 用量。
- 任务导入选择器支持全部 / Claude Code / Codex；切换设置页面保留扫描结果，退出应用后需重新扫描。
- 发送按钮旁“增强内容”使用当前所选模型和账号。编辑期间返回的旧增强结果不会覆盖新输入。

## 模型与安装范围

| 智能体 | 外部模型连接 | Windows 安装方式 |
| --- | --- | --- |
| Pi / OpenCode / MiMo Code | 支持已配置的兼容协议 | 应用内安装 / 更新 |
| Claude Code | Anthropic Messages | 应用内安装 / 更新 |
| Codex | OpenAI Responses | 应用内安装 / 更新 |
| Cursor / Grok / OMP | 当前使用 CLI 提供的模型目录 | 应用内安装 / 更新 |
| Hermes | 当前使用 CLI 提供的模型目录 | 官方安装入口，安装后指定路径 |
| ZCode | 官方 CLI 中配置的默认模型 | 按官方源码文档安装 CLI 后指定路径 |
| FX / Antigravity | 依上游支持 | 暂无本应用支持的原生 Windows CLI |

外部模型能否进行工具调用取决于服务商与模型本身。ZCode 使用官方 headless 模式，CLI 会拒绝必须交互审批的工具；不将桌面安装程序冒充 CLI。Hermes / Antigravity 尚不支持独立文本增强。微信集成仅使用开源本地传输，不使用 Cindy 云端。
