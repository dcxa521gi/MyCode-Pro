## 本轮实施范围

优先整合 MonoCode 与当前架构兼容的 Codex 异步问题、会话滚动与流式性能、文件拖入与工作树终端、Git/收件箱操作、技能索引、模型目录刷新、IME 和弹窗层级修复。保留 MyCode 品牌、Windows、已有模型路由、手机连接、群聊及存储位置。

MonoCode 新增 Mono 常驻智能体、习惯、浮动聊天、独立 Codex 存储与产物面板为另一套完整运行架构；当前 MyCode 已有群聊/IM/远程执行与项目存储，不将其宿主和数据目录直接覆盖到 MyCode。OpenCode 2.x 共享后台服务与 MyCode 自定义模型隔离配置尚未验证兼容，此项未移植，保留现有执行线路。本轮核对其设计与后续修复，未接入的模块逐项记录，不宣称已移植。

Cindy 优先核对本地自定义模型推理能力准入与资源释放；远程供应商分享、订阅计费、托管账号与云端远控不在本轮接入范围。Synara 核对禁用供应商一致性、工具/审批隔离、技能解析和恢复提示；不同服务端架构的调度与传输实现不直接复制。

## CLI 安装与更新

- 启动检测与设置页面共用版本状态，避免重复探测和提示不一致。
- 未安装显示“安装”；已安装且发现新版显示更新图标和“更新”，点击直接在应用内安装；检测确认无新版显示灰色不可点击“无新版”。
- 检测中、网络失败或无法识别版本单独显示状态并提供重试，不把检测失败显示为“无新版”。
- 支持语义版本、预发行版与日期版本；安装后验证新二进制并重新检测，保留已有凭据与会话。
- 不自动升级 CLI，不改变全局 CLI 的安装目录；应用内更新使用 MyCode 的受管目录。

## 验证与交付

验证三种按钮状态、异常重试、安装后状态更新与作用域切换；验证上游新增回归、前端类型/构建、Rust 检查与安装包资源。最终交付源码与 Windows 安装包至 dcxa521gi/MyCode-Pro，并核验公开下载。本轮不修改安卓客户端。
