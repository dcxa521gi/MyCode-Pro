# MyCode 0.19.0 功能补齐版（2026-10-09）

本次保持 0.19.0，重新整合 MonoCode v0.10.0 及 main `d26871f246d34479795bc9a00513b43d4d18add2`。此前 0.19.0 没有融合的常驻智能体、习惯任务、浮动聊天、Artifacts、Codex 专属存储和 OpenCode 2.x 已纳入实际代码与运行链路。

## 使用入口

- 侧边栏“常驻智能体”加号创建智能体；详情中设置名称、形象、项目、模型、权限、角色指令和记忆。
- “习惯任务”配置每小时、每日、工作日或每周执行，支持暂停、手动运行、结果回报、权限处理和失败恢复，单次最长一小时。
- 从托盘打开智能体浮动聊天，切换或创建智能体；文档产出物在浮窗中直接阅读，在主窗口中可查看活动、关联任务和项目变更、提交代码。
- 常驻智能体启动的任务可以显示在项目侧栏，完成后汇总回复；完整聊天记录保留，达到上下文窗口约 80% 时轮换原生会话并保留摘要。
- OpenCode 根据版本选择 1.x 或 2.x 协议；桌面 2.x 会话采用受管独立进程，保留自定义模型、工具授权、提问、审批、压缩、取消与恢复。
- 文件树支持方向键、Home/End、PageUp/PageDown、Enter/Space 和输入文件名前缀导航；实时活动可以从回复标题展开。

## 与 MyCode 融合

保留群聊、IM 推送与原任务继续、手机连接、登录、技能、用量统计、存储设置、任务计划浮窗和原有模型路由。常驻聊天也使用选区引用块、发送快捷键和编号续写。新智能体有自己的工作目录；旧数据继续原位读取。

Windows 使用托盘与独立聊天窗口适配上游 macOS 菜单栏。CLI 检测仍统一显示“安装”“更新”或灰色“无新版”，失败和无法比较时显示重试。FX、Antigravity、ZCode、omp 不重新开放。

Linux AppImage 复用 MyCode 发布源和 SHA-256 校验进行下载、更换与重启，保留旧文件用于回退；deb/rpm 使用包管理器。正式版与预发行版查询分离。系统 WebKitGTK 与打包检查随上游合入。
