## Cindy 与 Synara 本地能力核对

| 来源 | 基线变化 | 适用性与本版处置 |
| --- | --- | --- |
| Cindy | `832e5b74` → `77e2c32d`，195 提交 | 核对本地浏览器页面状态、移动草稿恢复、后台错误消除、任务和设备上限、沙箱路径转换及伙伴自主跟进。浏览器生命周期和错误收口可作为后续本地候选；跨设备同步、远程桌面和伙伴云调度依赖 Cindy 架构，本版未复制或宣称集成。已移除的旧群聊不恢复。 |
| Synara | `df87a48b` → `b8cf9382`，8 提交 | 核对模型切换恢复、长任务资源开销、编辑回滚前救援快照、OpenCode 停止恢复、Windows 进程观察、连接器令牌复用及缺失工作目录提示。它们主要在 Synara 服务端或 Electron 运行时，本版未复制为 MyCode 功能；MyCode 本轮采用 MonoCode 原生资源管理。 |

本轮不接入 Cindy 云服务，也不迁移、移动或删除已有项目、凭据、会话历史和旧群聊数据。独立群任务仍使用隔离目录，自动闲聊默认关闭且仅由用户开启并设置 Token 上限。已移除的 Freebuff、旧群聊入口和额外 CLI 更新提示不恢复。
