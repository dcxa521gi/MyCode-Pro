# MyCode 0.10.0

## 账号中心（测试功能）

左下角“设置”下方增加账号入口，明确标注测试功能、不代表最终品质。应用启动先核验：未登录显示登录框，已验证登录时不弹出。可选择稍后，继续使用本地功能。

授权在系统浏览器完成，只申请 profile；原生层生成短期 state 与 PKCE S256，先监听登记的 http://127.0.0.1:43821/callback，端口占用会报错，不改用未登记端口。授权码、访问令牌与刷新令牌不返回渲染层。Windows 使用当前用户 DPAPI 加密保存，刷新串行并原子替换；401/403、invalid_grant 清除本地登录。取消登录可使迟到回调失效。本地退出不是平台全局退出，彻底撤销需在账号中心操作。

公开配置在 src-tauri/src/account_center.rs，不需要环境变量、客户端密钥、管理员密码或业务服务器。未请求 email、组共享、会员、支付、证件等能力。macOS/Linux 的此实验登录目前仅保存在原生内存，退出软件需重新登录。

## 模型与会话

- 模型服务商改为卡片展示；从官方模型接口读取上下文、最大输出、输入模态和推理档位。小米接口只返回模型 ID 时，再读取小米官方模型表。官方未报告的字段显示“未提供”，不通过名称猜测 PDF 或其他模态。
- 自定义模型展示其已提供的推理档位；小米只公开思考开关时显示开关，不编造强度。上下文预算控制 MyCode 的圆环和自动压缩阈值，不改变上游模型的物理容量。
- Codex 支持 thread/compacted 与 contextCompaction 完成事件，压缩不再必须等到 turn/completed；增加超时处理。手动压缩不再因尚无用量读数而被禁用。只有提供压缩接口的代理可以执行压缩。
- Claude 生成标题使用当前自定义模型连接；过滤认证错误标题。官方模型认证失败调用该 CLI 的浏览器登录流程；自定义连接不会触发官方登录。各服务商的有效密钥、权限和额度仍需用户提供。

## TokenDance

在模型服务商选择 TokenDance 合作服务商，通过系统浏览器授权后粘贴一次性授权码（官方无回调模式），原生层用 PKCE 换取并保存 Key。请求使用 X-App-URL: app://example-desktop，key_name 为 MyCode；模型列表按已选接口协议过滤。不查询产品方分润价目。

原生授权及模型发现读取 TokenDance-Recovery-Action，并提示充值、重新授权或周期额度。外部 CLI 自己执行的推理请求目前显示 CLI 返回的错误；若 CLI 不透传恢复响应头，MyCode 无法直接读取该头。真实授权、计费推理和额度恢复尚需真实账号验收。

官方接入文档：https://tokendance.space/docs/ai-integration.md

## 更新、CLI 与浏览器

Windows 从 MyCode-Pro Releases 应用内下载安装包，校验 GitHub 发布资产的 SHA-256 与长度；左下角显示下载动效，完成后可查看更新说明、安装或跳过。下载安装分离，点击安装才退出并启动安装程序。其他平台尚无本仓库的应用内安装包。

OMP 接受官方 omp/版本号格式；安装后刷新 CLI 检测状态。Freebuff 从设置移除，已有历史不删除。FX、Antigravity 当前没有本应用可用的原生 Windows CLI 安装流程，ZCode CLI 需要源码构建或已有可执行文件；设置显示明确原因，不伪装安装成功。

浏览器安装从 @playwright/mcp 所在位置解析 Playwright，兼容 npm 嵌套依赖与平台全局安装目录。已使用修复命令实际下载 Chromium，并启动无头页面、执行按钮点击。未替换用户正在运行的应用，也未自动修改其浏览器配置。

## 收件箱与其他界面

GitCode 入口使用用户个人令牌查询 owner/repository 的 Issue/PR，每页 20 条，可查看描述、打开原页或复制任务背景。目前为独立查看入口，尚未接入原有收件箱的自动通知、未读同步和任务联动。Windows 令牌用 DPAPI 保存，其他平台仅原生内存保存。

技能可打开详情弹窗；权限菜单、工作区状态、消息操作和快捷键冲突补齐中文。外部应用增加 ZCode、Xiaomi MiMo、ChatGPT 检测；只有检测到安装后才显示。CLI 入口打开交互终端；ChatGPT 打开应用，不声明支持自动导入项目文件夹。

## 验证边界

自动化测试与页面检查不等于真实第三方账号验收。账号中心浏览器授权、TokenDance 授权及真实模型计费、GitCode 私有仓库访问、各 CLI 官方登录，均需实际账号交互；本轮不使用模拟身份声称通过这些验收。页面冒烟使用明确的测试响应；无头 Chromium 下载和启动使用实际二进制。
