# MyCode 0.24.1

本版在 0.24.0 基础上修复 Windows CLI 检测及安装，整理设置与输入区，扩展本地 IM 机器人。

## 功能变更

1. 移除 MiniMax Code、MiMo Code（小米 Code）的活动 CLI 入口、注册、模型选择和更新检查。历史会话继续保留，MiniMax/小米 API 模型供应商不受影响。
2. 启动失败或依赖缺失时，CLI 页面显示“修复安装”；联网版本检查失败显示“重试检测”。安装完整原生可选依赖，验证程序能够启动且版本正确后再切换至应用内版本。Grok 使用新的安装目录，避免重复使用损坏文件。错误日志收起，可展开查看。
3. 移除设置中的“电脑控制”。已保存设置页选择回退到有效页面，不修改历史数据。
4. IM 机器人增加插件更新区，可自动检查并下载兼容插件，也可手动更新。更新来自 MyCode 专用分支，校验协议、最低应用版本、下载大小、SHA-256 和脚本语法。活跃消息不因更新重启；下次启动生效，插件异常退出后下一次调用回退内置版本。
5. IM 增加 `/聊天`、`/任务`、`/自动化`、`/自动化创建`、`/暂停自动化`、`/恢复自动化`、`/帮助`，同时支持英文命令。日常聊天使用默认工作区内独立目录，不接入最近推送的项目任务；自动化按电脑本地时间执行，使用所选项目及模型，保留桌面工具审批。每个机器人授权用户只能管理自己从该机器人创建的定时任务。
6. 输入区只保留一处上下文用量，保留详细用量和压缩操作。
7. 移除左下角词元跳动账号入口，不改动“模型服务商”中的词元跳动授权和凭据。
8. 增加“简约工作室”主题，一键启用专注布局，提供浅色/深色中性配色、清晰边框及圆角。可从外观设置切回其他主题和布局。
9. 融合 Discord 终稿空白分段/Emoji 修复；补充 Devin Windows 备用安装路径，修复切换执行设备或账户时复用旧凭据路径的问题。

## IM 使用示例

```text
/聊天 今天帮我整理一下思路
/任务
/项目
/切换项目 2
/自动化创建 每天 09:00 | 项目日报 | 汇总这个项目的最近进展
/自动化
/暂停自动化 任务ID
/恢复自动化 任务ID
/帮助
```

MyCode 和电脑必须保持运行。定时任务中的工具审批仍在电脑端进行；日常聊天使用现有 CLI 和模型，不提供脱离电脑运行的云端机器人。真实渠道投递和账户登录需要用户现有配置进行验收。
