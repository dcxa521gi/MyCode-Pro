# MyCode 0.16.0

## 上游基线与本地能力对比

2026-10-04 对比上一 MonoCode 基线 `6bd432cada0f492f076cc93f7ccb3027f4ff7102` 与当前 main `00d68d342eff3adf23a320fa5e2be97d5e212683`。当前发布版仍为 v0.7.0。本次优先整合其 7 个新提交：PR/议题活动时间线与提交记录、工作区面板进入动画、权限独立弹窗、关联任务侧面板展开、剩余用量显示、侧边栏新会话插入动效和标题粒子效果。解决 MyCode 的语言、模型路由与独立工具页冲突，保留品牌及 Windows 支持。

对比 Cindy 本地开源检出 `bfb95c3492e8732497e08d296c8baeae04971e8f` 的设备控制协议/移动端快照和个性化记忆能力，以及 Synara `f308d699bc5b115108d8d0f5a45cecd3fa062888` 的项目、会话与执行环境分离和开发预览能力。采用电脑端作为唯一会话状态来源、移动端重取挂起审批快照，以及项目内测试与构建日志路径。未复制 Synara 实现，未接入 Cindy 云服务。

## 改动

- 界面缩放改为显示百分比的滑杆；修复用量历史代理筛选的实际值。
- CLI 设置作用范围、默认模型与 IM 代理/模型改为可搜索下拉，弹层不受卡片裁剪；IM 配置默认折叠。
- 个性化页加入自定义指令、关于你、记忆开关、明确记忆请求收集和项目记忆编辑/删除。保留旧记忆与 MCP 设置，不迁移旧数据。群聊不读取项目记忆。
- 修复模型管理页脚遮挡最后一项，长 CLI 版本/目录信息换行适配，安装期间使用统一加载指示。
- 新增手机连接，默认关闭：一次性限时配对、TLS 固定证书校验、令牌认证、设备撤销、变更请求去重。安卓首版支持项目会话列表、消息与工具活动、任务计划、原会话继续/暂停、待审批决策和选项问答。设备令牌使用 Android Keystore 加密；模型密钥不下发。
- 新增开发工具页：检测和配置微信开发者工具、DevEco/hvigor/hdc、adb、项目 Gradle Wrapper 与 Xcode，提供项目打开、预览、设备列表、构建/测试入口。日志保存在所选项目 `.mycode/tool-logs`。实际执行需要对应本地工具及项目配置；Mac/iOS 需 Mac/Xcode/签名，未声称 Windows 可以直接打包 iOS。
- 常规设置可启用任务期间阻止自动休眠，允许熄屏，完成后释放唤醒锁；手动休眠/关机/断网仍会中断运行。
- IM 通知绑定原项目、模型与会话，支持普通回复、通知引用和 `/continue` 定位。绑定保存在现有加密秘密存储中，重启恢复，过期或撤销后拒绝续接，不退回其他项目。多任务请引用对应通知或显式指定会话。
- 所有代理复用任务计划表：原生 todo/plan 状态优先；缺少原生事件时，从明确的中英文计划清单补充。每项状态显示待办、进行中、完成勾选或取消。任务停止和结束不会把未完成项自动标为完成；代码示例、引用和普通列表不当成计划。

## 验证与范围

构建、桌面/原生回归、IM 路由负向测试、界面双主题检查和安卓构建分别记录。安卓为 Debug 签名的首版测试包，功能范围见 `android/README.md`；尚未完成真实手机、真实 IM 账号回连、实际微信/鸿蒙项目构建或 Mac/iOS 签名验收。现有用户数据、凭据与会话不移动、不删除。群聊继续保持独立目录和记忆，默认关闭闲聊。
