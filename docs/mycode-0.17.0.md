## 需求与设计

- 修复安卓扫码入口：明确请求摄像头权限，专用扫码 Activity，拒绝权限、取消、启动失败均回到配对页面并给出提示；恢复 Activity 后仍保留页面。
- 修复直连配对：按 HTTP 内容长度读取响应、TLS 正常关闭，支持可选择的电脑地址与诊断错误，避免把失败统称为连接失败。
- 增加自部署远程中继服务。电脑主动向 HTTPS 中继建立长轮询，手机连接同一中继即可跨网络；手机/电脑共享配对中的 AES-256-GCM 密钥，服务只转发密文，注册凭据不下发手机。保留设备授权、原会话权限与变更去重。
- 安卓端显示电脑可用的代理/模型，允许空闲会话切换到有效模型；密钥仍在电脑执行环境，手机不保存供应商 API 密钥。
- 删除所有客户端界面的第三方云服务说明及相似无关文字。来源与许可记录保留在开发文档中。

## 边界与验收

远程模式需部署可公网访问的中继并配置 HTTPS 地址；交付服务不等于已经部署公网服务。手机和电脑都需要能够访问该地址，电脑必须保持运行。直连可用于局域网、VPN 或已有可达地址。

验证分别覆盖 Android 单元/构建/Lint、加密与路由负向测试、原会话模型选择、电脑/手机页面检查、桌面原生回归、安装包内容和公开下载校验。真实手机摄像头与公网部署必须单独记录，不能用页面模拟代替。
