## 本次修改

- Windows 更新通知与设置里的安装按钮共用内置 Node/npm 安装器。直接校验安装返回的可执行路径版本，再激活；失败或仍旧版本不会替换有效配置。不依赖 PATH 中额外安装 npm，不改用户全局 CLI 和登录凭据。
- CLI 更新反馈、侧栏、连接页、智能体创建/偏好/状态、菜单、会话审阅、文件操作与设置补齐双语言。默认智能体名称根据语言显示，自定义名称原样保留；智能体模型上下文使用 MyCode 品牌。
- CLI 设置恢复上游紧凑列表结构，保留 MyCode 的额外 CLI、自定义模型路由和可搜索模型选择。
- 模型服务商采用上游账户式列表展示；保留详情管理、模型开关和主模型设置。“词元跳动”使用主题一致的授权卡片；内部 ID、API 地址和用户已有配置不变。
- 移除新建群聊入口、群聊界面、调度器及原生写入命令，既有群聊目录和会话记录保留。
- Windows 任务检查点统一原生路径与保存后的路径格式，修复重叠会话漏检共享工作区的问题，避免错误撤销其他会话的修改。
- AppImage 重打包支持 MyCode 的可执行文件名并兼容旧名称，保留宿主共享库检查、原 runtime 和重打包后的签名流程。新增完整脚本回归，真实 Linux 打包仍由 CI 验证。
- 默认 CLI 账号、CLI 配置说明及账号副标题在显示时根据语言翻译，保留保存的账号名称和自定义标签；语言切换不会仅影响首次打开页面。
