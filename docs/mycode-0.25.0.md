# MyCode 0.25.0：模型组、本地工作流插件与分阶段编排

日期：2026-11-24。开发基线：0.24.1 / `e371a239ea`。交付状态：实现与验证中，尚未发布安装包；以本文后续交付记录为准。

## 实际新增

### 模型组调度与多账号来源

- 设置 → 模型服务商 → **模型组与账号池**：创建、编辑、删除模型组，选择代理、模型来源和独立账号。
- 同一代理的不同 API 供应商及不同已登录账号可以作为来源；Claude Code、Codex 复用原有隔离账号配置，Devin 保持原有单账号边界。
- 五种策略：按顺序、轮流、用完再换、余量最多优先、平滑加权。权重支持 1–100。
- 星期与时段例外：首条命中生效；跨午夜按开始那一天计算，使用电脑本地时区。
- 用户手动勾选“用于新会话”后才启用。首次有效发送确定模型和账号，已有会话保持原路由，未发送的预览不消耗轮转次数。
- 配额排名优先使用周/月长窗口；任一有效窗口耗尽都会排除来源。超过五分钟的额度快照不冒充实时额度，未知额度明确显示未知。API Key 来源不套用 CLI 订阅额度。
- 已移除账号、停用来源、无模型或未安装代理不可选。全部不可用时拒绝发送并保留输入，不擅自使用其他账号。
- 权重或来源发生变化后清零旧调度计数；组设置不移动、覆盖任何凭据。

边界：本版调度在**本机新会话**首次发送时生效；不在已有会话中悄悄切换账号，不自动重放失败任务，不包含跨电脑模型组或动态 ACP 插件引擎账号池。原有会话额度耗尽后的账号切换入口继续保留。

### 本地工作流插件

- 设置 → MCP 中新增“本地工作流插件”，可导入 JSON 清单、审阅工作流指令、安装/更新、启停和卸载。
- 新导入/更新的插件默认停用，需手动启用。支持命名工具、多工具清单，以及文本、长文本、选择、开关四种原生表单字段。
- 插件所有名称、说明、字段文案和指令均要求英文、简体中文双语。
- 启用 `/operator` 的会话及已有应用访问能力的智能体可以用 `plugins.list`、`plugins.run`、`plugins.result` 发现工具、请求表单、读取确认结果。
- 表单确认后回到原会话继续；结果按会话隔离，同一请求不会重复弹表单，更新/停用插件后旧表单不得直接确认，停止任务取消其等待表单，十分钟未处理自动取消。
- 表单在普通界面刷新时保持输入；结果只提供用户确认的参数与工作流指令，继续使用原有项目权限和审批流程。
- 可导入示例：[项目审查插件](examples/project-review.plugin.json)。

边界：这是 MyCode 原生的**声明式工作流插件**，不是 Cindy 插件二进制兼容层。不安装嵌入式 JS/HTML、远程页面、ACP 供应商引擎或其登录适配器；不能声称已完整搬入 Cindy 插件生态。插件数据存于本机应用配置，未增设任何云服务。

### 远程连接优化

- 按机器 ID、配对环境 ID、项目 ID 隔离远程模型目录。
- 同一目录十五秒内共享新鲜快照，并合并并发读取；挂起读取二十秒超时，可继续重试。
- 临时错误保留旧模型条目供显示，并显示现有错误状态；权限撤销/拒绝或成功返回空列表时不恢复旧条目。
- 连接恢复、目录到期、打开选择器时刷新；界面不可见时不继续周期刷新。
- 目录异常时不能以旧缓存新建会话；已有会话保存的模型与参数仍可显示，执行权限仍由远端验证。
- 远程选择器继续过滤明确退役的代理，不因兼容协议枚举而重新启用。

边界：此次改动针对桌面 MyCode 的远程 Host 会话模型目录；不宣称完成手机异网/VPN 真机验证，也未引入 Cindy 设备账号、云分享或中继基础设施。

### 多智能体分阶段编排

- 原有编排增加 `delegate_wave`：每阶段 1–20 个任务，每次编排最多 40 个任务。
- 整批检查代理/模型、文件范围和依赖图，校验完成后一次性写入持久化状态与请求回执，不创建半批任务。
- 阶段内部 `dependsOn` 使用本阶段分配 ID；`after` 引用之前阶段的任务 ID。依赖任务经过主管审查接受后，后续任务才运行。
- 同一请求 ID 重试返回原阶段与任务 ID；换参数复用 ID 会报冲突。
- 异步准备期间再次校验运行状态、主管原用户轮次、权限模式、依赖任务和模型可用性。停止、收到新用户轮次或权限变化时不恢复旧派发。
- 侧边栏编排智能体行显示阶段名称。保留原有独立工作副本、文件范围、审批、审查集成、停止与恢复机制。

示例：先 `list` 取得真实代理/模型 ID，再调用 `delegate_wave`；具体 JSON 见 `MyCode.exe control --help`。未启用编排的普通任务不能越权调用。
