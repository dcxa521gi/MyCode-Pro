# MyCode 0.27.0 更新与融合清单

本版修正 Magpie 接入方式，重做媒体工作台导航与创作编辑器。保留已有模型自动分类、ACP 引擎、跨设备模型组、账号接续、IM 和项目会话功能；没有恢复用户明确移除的功能。

## Magpie 接入修复

添加服务商时选择 Magpie，按照网关实际地址填写密钥。一个连接提供三个可独立编辑的接口：Claude Code 使用 Messages，Codex 使用 Responses，Pi / OpenCode 使用 Chat。默认本机端口 3425；Claude 地址不带 /v1，其他默认带 /v1。新增接入教程入口。

- 同一来源的模型可在兼容代理中选择；厂商原生协议不再错误限制网关转发协议。
- 模型主名称与供应商分开显示，重名供应商显示标识以便区分。
- 完整模型路由不裁剪，保持不同账号/供应商下同名模型的独立性。
- 模型刷新清除过期来源信息，保留明确的手动名称和能力标签覆盖。
- 空模型目录会验证 Magpie 身份并提示在网关中启用模型；错误或畸形响应不会显示为正常空目录。
- 身份探测不携带密钥，接口禁止自动重定向；更换运行时地址需要重新提供密钥。

来源：参考 Cindy 已开源的本地 Magpie 模板、模型来源和发现规则，在 MyCode 的原生模型连接链路中实现。模型发现、来源展示和代理执行共同使用这套接入配置。

## 媒体工作台

所有侧边栏入口、页面标题统一为“媒体工作台”，英文为 Media Workbench。页面左侧固定显示写作、图片、视频、设计分类及子功能；右侧显示选中工具的专用编辑器、模型与输出设置以及本工具的创作历史。

| 分类 | 工具 | 专用操作与输出目标 |
| --- | --- | --- |
| 写作 | 生成小说 | 题材、叙事视角、章节数、每章字数、人物设定、章节大纲；章节稿件与一致性校对 |
| 写作 | 生成短剧 | 集数、每集时长、角色关系、结局悬念、剧本形式；分集大纲、对白与拍摄分镜 |
| 图片 | 文生图 | 画布尺寸、风格、生成数量、排除内容；真实图片接口 |
| 图片 | 图生图 | 原图、修改目标、保留细节、尺寸、风格；参考图编辑接口 |
| 图片 | 图像复刻 | 构图/配色/光影/风格参考重点、差异元素、尺寸与排除内容 |
| 图片 | 图转提示词 | 分析重点、中英语言、结构化字段或 JSON、目标生成模型 |
| 视频 | 文生视频 | 画幅、时长、镜头运动、光线与氛围、排除内容 |
| 视频 | 图生视频 | 首帧图片、主体运动、镜头运动、保持不变元素、画幅与时长 |
| 视频 | 视频复刻 | 参考时间范围、镜头保留/调整、目标时长、声音旁白；抽帧、重建、成片检查 |
| 视频 | 视频转提示词 | 分析片段、抽帧间隔、语言、镜头转场重点；逐镜头时间轴与提示词 |
| 视频 | 生成短视频 | 时长、横竖屏、分镜脚本、旁白、字幕输出；素材、剪辑与成片 |
| 设计 | 生成绘本 | 阅读年龄、页数、角色外观、视觉风格、分页内容、PDF/HTML 输出 |
| 设计 | 生成 PPT | 受众、页数、页面比例、设计方向、内容资料、逐页演讲备注；可编辑 PPTX |

小说/短剧提供稿件结构，视频提供制作流程与分镜说明，绘本/PPT 提供页序结构预览，图片提供画布比例与步骤说明。结构预览明确标注为规划，不能冒充模型生成的结果。

各工具分别保存创作描述、参考文件和参数草稿；切换工具后可恢复。模型选择分别记录，历史按当前工具筛选。右侧“模型与输出”集中设置生成模型、媒体辅助模型和输出目录。图片/视频结果沿用真实文件预览、进度刷新及打开目录功能。

## 参数和生成行为

- 数量、尺寸、时长真正写入兼容媒体接口的 JSON 或 multipart 请求，不只是展示选项。
- 其他创作要求组成具体提示词或智能体任务说明，包括章节、分镜、分页、字幕等。
- 先检查数字范围、选项值和参数名；接口端点仍由用户选择的服务商决定。
- 提交记录包含参数，不能使用同一任务编号改变配置或重复计费提交。
- 原项目目录、产物目录、模型能力标签及手动修正继续保留。

兼容边界：不同模型对画幅、时长和批量数量支持不同，默认使用模型默认值，拒绝参数会显示真实服务商错误。图片、视频需要兼容媒体接口；小说、剧本、绘本、PPT、短视频制作依赖所选智能体及其可用本地工具。不会把文稿误报为已生成的视频或图片。
