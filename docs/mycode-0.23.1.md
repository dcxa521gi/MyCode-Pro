## 本版变更

- 侧栏“新建任务”和“IM 机器人”之间新增“群任务”。可创建独立群任务，指定现有项目目录或默认工作区，为成员设置昵称、职责、性格、CLI 和模型，指定一位主管。群消息由成员依次回复，主管最后复核；`@成员名` 可优先点名。自动闲聊默认关闭，用户可设置随机间隔和 Token 上限后手动启用。每个群任务的聊天、安排、记忆保存在所选目录的 `.mycode/group-tasks/<群 ID>/room.json`；应用数据目录只保存定位索引。原 `group-index.json` 和旧 `.mycode/groups/` 不参与新功能。
- 主管可将任务目标拟成安排卡。用户可调整每步负责人，并逐步点击开始/继续；每一步都运行实际所选 CLI 与模型，产出交接记录后停止等待下一次确认。执行时可打开对应智能体会话处理审批。Token 上限阻止后续新回合，但运行中的回合可能超过上限；模型未报告用量时无法精确计费。
- IM 机器人页增加对话命令教程，覆盖 `/项目`、翻页、`/切换项目`、`/新建项目`、普通任务消息、回复完成通知、`/continue` 和远程继续的启用条件。
- 词元跳动账号卡增加“退出登录”。退出只改变本机账号界面会话状态，不删除或修改设置中的词元跳动模型连接和密钥；再次登录须重新完成词元跳动授权。
- 右上角 CLI 更新提示支持展开/折叠。折叠后只保留一行当前正在更新的 CLI 信息；没有进行中的更新时显示一行待更新项。新增界面和反馈提供简体中文与英文。
