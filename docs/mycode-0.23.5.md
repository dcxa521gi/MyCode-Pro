## 融合范围

- **桌面操作**：新版侧栏支持左右滑动项目，项目与收件箱菜单支持鼠标右键、菜单键和 Shift+F10。无项目时可直接打开项目和设置。保留 MyCode 首页、模型路由、Windows 窗口行为和独立群任务。
- **手机伴侣源码**：手机端可配对桌面、查看项目和会话、发送消息、跟随回复、停止回复、查看 Git 改动。上游行为作为新连接流程；MyCode 既有 Android 控制端另保留在“旧版 Android 控制端”，原生命令改用 `legacy_mobile_*`，不迁移或清除既有项目、会话和凭据。新手机端使用独立的 MyCode 图标、URL scheme、包标识和密钥命名；移除上游 Expo 账号与更新项目绑定。
- **语言**：桌面新配对页、二维码、状态、确认与错误提供英文和简体中文；手机端静态界面、常见连接/附件/会话反馈按设备语言显示英文或简体中文。用户名称、消息和文件原文不翻译。手机端的原生系统权限文案与远端返回的任意错误仍需设备层验证。
- **公开分发边界**：本版仅交付 MyCode Windows 桌面安装包和源码。手机工程需要另行签名、构建和设备验收；桌面设置明确提示没有随桌面发行包提供手机安装包。旧版本 Host 包不因本次桌面更新而删除。
