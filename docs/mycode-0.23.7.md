## 启动修复

0.23.6 为修复选完项目后的白屏，在连接电脑前就挂载了完整会话工作区。0.23.7 改为先挂载最小路由和配对/工作区选择页，完成选择后再初始化会话提供器、原生场景与完整导航；启动阶段的深链路页面由受保护路由返回首页。这样避免会话 UI 在配对之前争用 Android 首帧，同时保留选择项目后继续进入会话的路径。

签名 APK 流水线新增 Android 模拟器启动冒烟检查：安装正式 APK、启动应用、检查进程存活以及配对页的可访问文本，并保存 UI 树、屏幕截图与 crash log。该检查不能替代用户设备的覆盖安装、扫码和远程连接验收。
