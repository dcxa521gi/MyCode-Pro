## 实现与使用

### 手机连接与独立使用

- 直连默认优先选择实体 Wi-Fi/以太网的私网地址，二维码与复制信息携带地址列表；手机可切换地址而保持原证书指纹与一次性配对身份。
- Android 对同一 IPv4 子网的直连地址尝试使用对应 Wi-Fi/以太网网络，绕开 VPN 虚拟路由。系统的 VPN 锁定策略仍可能禁止此访问；两端 VPN 应允许局域网，跨网络则使用 HTTPS 中继。
- Windows 手机连接页新增防火墙授权按钮，点击后使用系统 UAC 确认，规则仅允许当前 MyCode 可执行文件在专用/域网络上接受本地子网 TCP 请求。没有自动开放公网端口。
- 手机模式可配置多个自己的 HTTPS OpenAI Chat Completions / Anthropic Messages 服务商，创建独立文本会话。模型配置、密钥与历史使用 Android Keystore + AES-GCM 加密保存；独立模式不执行电脑 CLI。
- 电脑模式自动轮询同步电脑项目、会话、计划、工具活动和权限请求，可以继续原会话。手机独立会话仍保存在手机，不自动合并到电脑，不复制电脑 API 密钥。切换模式保留已有设备配对。
- 沿用固定 Release 签名，0.17.0 安卓端可覆盖升级；旧 Debug 签名安装首次需要另行处理签名冲突。

### 自动休眠与合盖

默认在整个 MyCode 运行期间持有系统唤醒请求，允许屏幕自动关闭。Windows 复制当前电源方案，在临时方案中把接电/电池合盖动作设为不执行操作；退出、隐藏的退出监控进程和下次启动恢复原方案。用户主动改选其他方案时优先尊重用户选择。权限/平台不支持时显示真实错误。手动休眠、关机、强制策略、低电量和网络断开不属于唤醒请求能够保证的范围，不能承诺永不断连。

### 模拟器自动测试

开发工具设置提供小程序/鸿蒙“自动测试”，Agent 获得同一命令入口，在常规执行权限规则下调用。测试结果写入项目 `.mycode/test-results/<运行ID>/result.json`，微信页面截图也保存在该目录。

- 微信：已安装开发者工具并开启 CLI/自动化授权，项目有 `project.config.json`。默认检查当前模拟器页面、截图与运行异常；可配置 `.mycode/wechat-tests.json`，例如 `{"pages":["pages/index/index"],"checks":[{"method":"Page.getData","params":{"pageId":"已获取的页面ID"},"expected":{}}]}`。自定义断言只接受本地 Page/Element 方法，不暴露发布或云管理 RPC。没有配置业务断言时只标记页面烟雾检查。
- 鸿蒙：已安装 DevEco SDK 与本地模拟器，项目有 `build-profile.json5`，先构建匹配模拟器的已签名应用及 ohosTest HAP。配置 `.mycode/harmony-tests.json`，例如 `{"bundle":"com.example.app","module":"entry_test","hap":"entry/build/default/outputs/default/entry-default-signed.hap","testHap":"entry/build/default/outputs/ohosTest/entry-ohosTest-signed.hap","emulator":"nova 16 Pro"}`，可设置 `port` 和 `runner`。程序启动指定本地模拟器、连接 hdc、安装项目内 HAP、执行 Hypium，并校验测试输出。缺少签名、SDK、授权或测试报告时返回失败。
