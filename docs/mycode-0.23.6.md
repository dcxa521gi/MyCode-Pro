## 修复

1. Android 原生清单曾包含 `android.permission.CAMERA` 的 `tools:node="remove"`，使扫码无法申请权限。现在相机权限在 Expo 配置中明确声明，图片选择插件不再删除它；扫码权限请求失败时给出中文/英文提示并保留粘贴配对链接的路径。
2. 手机根导航器在配对和选择项目阶段始终挂载，引导界面覆盖在其上，避免选完项目后首次挂载并立即导航造成白屏。项目进入按钮和辅助说明按设备语言显示。
3. 桌面新版项目菜单提供“切换到经典布局”，与设置 → 外观中的原开关同步；中文环境下的工作树、项目、项目设置、设置及布局切换菜单已汉化。
4. 设置列表删除“旧版 Android 控制器”，旧设置定位自动转到“连接”。旧控制器运行代码和现有数据不因本次入口移除而清理。
