# MyCode 安卓控制端

版本 0.16.0。首版连接电脑执行任务，不在手机安装代理 CLI，也不向手机传递模型密钥。

电脑打开「设置 → 手机连接」，开启后在安卓端扫描二维码或粘贴配对信息。手机和电脑需通过同一可信局域网或已有 VPN 互通；防火墙需允许所显示的端口。未提供公网中继。配对信息请勿分享，单次使用、十分钟有效。TLS 固定证书校验；桌面端重启或关闭连接会撤销授权，需重新配对。手机使用 Android Keystore 加密保存设备令牌，禁用应用备份。

已实现：按项目查看会话、搜索会话、读取消息和最近工具活动、查看任务计划、继续原会话、暂停任务、允许/拒绝待审批操作、回答有选项的澄清问题。前台自动刷新，切换会话保留本次草稿，返回前台重新获取快照。会话历史只在内存显示，不在手机建立数据库。电脑仍是会话和权限状态的唯一来源。

首版范围：尚不支持手机创建项目、文件编辑、群聊、无选项的自定义问答、计划审阅编辑和系统后台推送。电脑必须开机并运行 MyCode；手动休眠、关机和断网无法继续执行。真实手机配对、权限审批和弱网行为需实机验收。不能把页面模拟测试作为实机验收。

构建：JDK 17、Gradle 8.9、Android SDK 35；运行 `gradle -p android assembleDebug lintDebug --no-daemon`。GitHub Actions 使用预装 SDK 的构建机器。输出 `android/app/build/outputs/apk/debug/app-debug.apk`。交付为 Debug 签名测试 APK，不表示已通过商店发布或正式签名验收。

二维码扫描使用 ZXing Android Embedded 4.3.0（Apache 2.0）；不接入 Cindy 云服务。
